# Support

DarwinTV is a research project, not a product.

- **Questions and design discussion:** GitHub Discussions.
- **Bug reports:** use the issue template and include the serial log.
- **Security:** follow `SECURITY.md`; do not open a public issue.
- **Apple firmware / IPSW questions:** not supported here; use the upstream projects and
  Apple's own documentation.

Please do not ask for Apple IPSWs, decryption keys, activation bypasses or prebuilt Apple
userland images. Those requests will be closed.
